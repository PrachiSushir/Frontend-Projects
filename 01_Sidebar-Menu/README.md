# Sidebar Menu

A simple and interactive sidebar menu built using HTML and CSS.
The sidebar can be opened and closed using a hamburger menu and includes navigation items, icons, hover effects, and social media links.

## Features

- Hamburger menu to open the sidebar
- Close button to hide the sidebar
- Navigation menu with icons
- Background image
- Hover effects
- Social media icons
- Smooth opening and closing animation

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts (Poppins)

## How to Run

1. Clone the repository.
2. Open the `Sidebar-Menu` folder.
3. Open `index.html` in VS code and click **Go Live** using Live  Server extension 
4. Click the hamburger icon to open the sidebar.
